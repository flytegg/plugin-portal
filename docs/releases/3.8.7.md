# PluginPortal 3.8.7

- Added external plugin management through YAML adapters, including GitHub release downloads, imports, managed filenames, and recognition exclusions.
- Added `/pp list --outdated` with marketplace and external plugins in one view. Use `/pp list --external` for external plugins only.
- Added `/pp search` for related results while keeping `/pp install` and `/pp view` focused on unique exact-name matches. Duplicate names now include provider IDs for disambiguation.
- Added `/pp update <plugin> --refresh` to bypass cached marketplace metadata after a plugin release.
- Improved compatible-version selection across Paper, Folia, SpigotMC, Hangar, Modrinth, and Polymart. Plugin Portal now checks full paginated version histories when the cached results do not contain a compatible build.
- Added free Polymart download support. Paid Voxel Shop and Polymart plugins remain visible for entitlement checks but cannot be downloaded or updated through Plugin Portal.
- Preserved marketplace identity during imports and prevented incompatible Plugin Portal self-updates.
- Migrated older `plugins.json` entries that do not contain an `entryId`, so existing servers can replace the JAR without rebuilding their managed-plugin state.
- Fixed missing command output on newer Paper builds, stuck `Loading...` suggestions, already-installed output, command separator spacing, and several noisy multi-line install and update results.
- Added safer premium entitlement validation and restored supported marketplace license-key imports without treating placeholder values as real keys.
